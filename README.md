# RaceDay

RaceDay is an event management system designed for race organisers and participants.

The system allows organisers to create and manage race events, categories, participant enrolments and results. Participants can register, enrol in race categories and view their race results. 

## Part 1

Part 1 of the project includes:

- Entity Relationship Diagram (ERD)
- SQL database creation script
- API Endpoint Plan
- GitHub repository and version control
- GitHub Actions CI/CD workflow
- Video presentation

The repository contains the following main files/folders:

- `README.md` - Project information and setup instructions

## Database Setup Instructions

1. Open SQL Server Management Studio (SSMS).
2. Connect to your SQL Server instance.
3. Open the RaceDay SQL script included in the repository.
4. Execute the script.
5. The script will create the RaceDay database and the required tables.
6. Confirm that all tables were created successfully.

## API Endpoint Plan

The API Endpoint Plan documents the planned RaceDay API endpoints.

Each endpoint includes:

- HTTP method
- Route
- Description
- Required role
- Request body
- Expected response codes

The API covers Authentication, User Profiles, Events, Categories, Event Enrolments and Results.
